# OctoAcme Project Management Docs

This directory contains the core project management guidance used by OctoAcme. The collection is designed to help teams align on how work is initiated, planned, executed, communicated, released, and improved over time.

## Project management process overview

OctoAcme uses a lightweight, cross-functional project management model built around clear ownership, iterative delivery, and measurable outcomes. The process typically flows through these stages:

- Initiation: validate the business need, confirm stakeholders, define success metrics, and decide whether to move forward with planning.
- Planning: create the backlog, estimate work, align milestones, define the Definition of Done, and identify dependencies and risks.
- Execution: run daily or weekly coordination, track progress in the project board, manage blockers, and maintain quality through reviews and testing.
- Risk & communication: document dependencies, share status with stakeholders, escalate issues when needed, and keep a single source of truth for updates.
- Release & deployment: confirm readiness, deploy with a controlled rollout plan, validate the outcome, and communicate changes to stakeholders.
- Retrospective & improvement: review what went well, capture lessons learned, and turn action items into improvements for the next cycle.
